## Unified Interface

All models share a common interface with built-in retry and fallback mechanisms:

### call() Method

The primary method for model inference. Supports both streaming and non-streaming responses.

```typescript
const response = await model.call({
    messages: [userMessage, ...context],
    tools: toolSchemas,
    toolChoice: 'auto',
});
```

### Retry Mechanism

Automatically retries failed requests with exponential backoff:

```typescript
const model = new OpenAIChatModel({
    modelName: 'gpt-4o',
    apiKey: process.env.OPENAI_API_KEY,
    maxRetries: 3, // Retry up to 3 times on failure
});
```

### Fallback Support

Automatically switches to a fallback model if the primary model fails:

```typescript
const model = new OpenAIChatModel({
    modelName: 'gpt-4o',
    apiKey: process.env.OPENAI_API_KEY,
    fallbackModelName: 'gpt-3.5-turbo', // Use this if gpt-4o fails
});
```

## Model Implementations

### OpenAI

```typescript
import { OpenAIChatModel } from '@agentscope-ai/agentscope/model';

const model = new OpenAIChatModel({
    modelName: 'gpt-4o',
    apiKey: process.env.OPENAI_API_KEY,
    stream: true,
    maxRetries: 3,
    baseURL: 'https://api.openai.com/v1', // Optional custom endpoint
    presetGenParams: {
        temperature: 0.7,
        top_p: 0.9,
    },
});
```

### DeepSeek

import { DeepSeekChatModel } from '@agentscope-ai/agentscope/model';

const model = new DeepSeekChatModel({

### Gemini

```typescript
import { GeminiChatModel } from '@agentscope-ai/agentscope/model';
import { createMsg, TextBlock } from '@agentscope-ai/agentscope/message';

const model = new GeminiChatModel({
    modelName: 'gemini-3.8-flash',
    apiKey: process.env.GEMINI_API_KEY!,
    stream: false,
    presetGenParams: {
        temperature: 0.7,
        maxOutputTokens: 1024,
    },
});

const response = await model.call({
    messages: [
        createMsg({
            name: 'user',
            role: 'user',
            content: [TextBlock({ text: 'Explain how a rainbow forms.' })],
        }),
    ],
});
```

This adapter uses the Gemini Developer API's native `generateContent` and
`streamGenerateContent` endpoints. `baseURL` can override the API root (including
its version); Vertex AI authentication is not supported. No Google SDK dependency
is required. A `GeminiChatFormatter` is provided automatically and can also be
imported from `@agentscope-ai/agentscope/formatter`.

Pass native camelCase generation settings in `presetGenParams`, or override them
per call using `generationConfig`. Per-call `safetySettings` and `signal`
(`AbortSignal`) are also supported. The adapter uses the first response candidate.

Function calling supports `auto`, `none`, `required`, and a specific function name.
Tool schemas use Gemini's `parametersJsonSchema` field. Parallel function calls are
returned as separate pending tool-call blocks; their results are grouped into one
user turn on the following request. `callStructured` uses the base class's named
function-calling mechanism. Function arguments are received as complete objects;
experimental partial function-argument streaming is not supported.

With `stream: true` (the default), `call()` returns an async generator. Each yield
contains incremental content; the generator's return value contains the complete
response and the final token usage, including thought tokens. The `Agent` consumes
both automatically. When using the generator directly, read it with `.next()` if
you need the return value; a `for await` loop only exposes the deltas.

The formatter accepts inline base64 data and Gemini-compatible file URIs.
HTTP image URLs are not downloaded automatically: use the Gemini Files API or
supply base64 data. Signed response parts retain an optional `thought_signature`
field through message schema parsing. Keep these blocks intact in saved history;
dropping their signatures can cause Gemini to reject subsequent tool turns.
Unsigned thought summaries are omitted from replay.

### Ollama

```typescript
import { OllamaChatModel } from '@agentscope-ai/agentscope/model';

const model = new OllamaChatModel({
    modelName: 'llama3.1',
    host: 'http://localhost:11434', // Ollama server address
    stream: true,
    keepAlive: '5m', // Keep model loaded for 5 minutes
    thinkingConfig: {
        enableThinking: true,
        thinkingLevel: 'medium',
    },
    options: {
        temperature: 0.7,
        num_ctx: 4096,
    },
});
```

## Common Parameters

<ParamField path="modelName" type="string" required>
    Model identifier (e.g., 'gpt-4o', 'deepseek-chat', 'qwen-max', 'llama3.1')
</ParamField>

<ParamField path="apiKey" type="string" required>
    API key for authentication (not required for Ollama)
</ParamField>

<ParamField path="stream" type="boolean" default={true}>
    Enable streaming responses for real-time output
</ParamField>

<ParamField path="maxRetries" type="number" default={0}>
    Maximum number of retry attempts on failure
</ParamField>

<ParamField path="fallbackModelName" type="string">
    Fallback model to use if primary model fails
</ParamField>

<ParamField path="presetGenParams" type="Record<string, unknown>">
    Default generation parameters (temperature, top_p, etc.)
</ParamField>
