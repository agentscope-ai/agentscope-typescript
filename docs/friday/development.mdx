## Development Setup

### Prerequisites

- Node.js 20.0.0+
- pnpm 9.0.0+
- Git

### Clone and Install

```bash
git clone https://github.com/agentscope-ai/agentscope-typescript.git
cd agentscope-typescript
pnpm install
```

### Project Structure

```
apps/desktop/
├── src/
│   ├── main/           # Electron main process
│   │   ├── runtime/    # Shared Service composition adapter
│   │   ├── services/   # Transport-only IPC and local document data
│   │   └── index.ts    # Entry point
│   ├── renderer/       # React frontend
│   │   ├── components/ # UI components
│   │   ├── hooks/      # React hooks
│   │   └── pages/      # Page components
│   ├── preload/        # Preload scripts
│   └── shared/         # Shared types
```

## Development Workflow

### Run in Development Mode

```bash
cd apps/desktop
pnpm dev
```

### Build for Production

```bash
pnpm build
```

### Run Tests

```bash
pnpm --filter @agentscope-ai/desktop test
```
